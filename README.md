# 📱 Flipkart Mobile Market Analysis using Web Scraping

## 📌 Project Overview
This project demonstrates an end-to-end data analytics workflow by collecting smartphone data from Flipkart using Python-based web scraping techniques. The scraped data was cleaned, preprocessed, and analyzed to uncover meaningful insights into smartphone pricing, brand distribution, RAM, ROM, battery capacity, display size, and other key specifications.

## 🎯 Business Objective
- Analyze smartphone market trends using real-time data from Flipkart.
- Compare smartphone brands based on price and specifications.
- Identify popular smartphone configurations and pricing patterns.
- Generate business insights to support pricing strategies and product analysis.

## 🛠️ Technologies Used
- Python
- Requests
- BeautifulSoup
- Regular Expressions (Regex)
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Project Workflow
1. Web Scraping from Flipkart
2. Data Collection
3. Data Cleaning & Preprocessing
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Business Insights & Recommendations

## 📂 Dataset Features
- Brand
- Model
- Price
- RAM
- ROM
- Display Size
- Battery Capacity
- Color

## 🔍 Key Insights
- Samsung has the highest number of smartphone listings in the dataset.
- Most smartphones belong to the Budget and Mid-Range price segments.
- 6 GB and 8 GB RAM are the most common memory configurations.
- 5000 mAh is the most frequently available battery capacity.
- The analysis reveals pricing trends, brand popularity, and smartphone specification patterns.

## 💼 Business Recommendations
- Focus on expanding Budget and Mid-Range smartphone offerings.
- Maintain inventory for high-demand configurations such as 6 GB/8 GB RAM and 5000 mAh battery models.
- Use pricing and specification insights to improve product positioning and marketing strategies.

## 🚀 Conclusion
This project demonstrates how web scraping and data analytics can transform raw e-commerce data into meaningful business insights. It showcases practical skills in Python, web scraping, data preprocessing, exploratory data analysis, and visualization, providing valuable support for data-driven decision-making.
